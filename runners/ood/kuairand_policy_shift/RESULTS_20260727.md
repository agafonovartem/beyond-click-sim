# KuaiRand standard-to-random result

Date: 2026-07-27

Status: complete historical GPT-5.4-mini exploratory run under the same task
construction. The active [`PROTOCOL.md`](PROTOCOL.md) now pins GPT-5.5 for the
stronger-model replication.

## Setup

- Dataset: KuaiRand-Pure canonical v1.
- Source: non-random `tab=1` exposures from 2022-04-08 through 2022-04-21.
- Buffer: 2022-04-22.
- Validation window: 2022-04-23 through 2022-04-30.
- Test window: 2022-05-01 through 2022-05-08.
- Test target regimes:
  - future standard exposures, used as a temporal reference;
  - future randomized exposures, used as the temporal plus exposure-regime
    OOD target.
- Target: the released binary click/valid-play interaction signal.
- Test cohort: 500 users selected without target labels.
- Visible GPT history: the latest 20 distinct source interactions for each
  user, including observed binary responses.
- Candidate group: ten natural logged exposures for the same user and target
  regime.
- Candidate seeds: `0,1,2`.
- Candidate metadata: GPT-5.5 English translations of caption, cover text, and
  hierarchical category.
- Primary item pool: 4,098 common-warm items with at least 20 source exposures
  and five distinct source users.
- Pair novelty: every target row is the first released exposure of that
  user-item pair across all tabs and both exposure regimes.
- No negative items are generated and labels are not balanced.
- All-zero and all-positive groups remain materialized but are excluded from
  ranking metrics.

The source contains 820,534 rows, 25,114 users, and 7,158 items. The English
semantic artifact contains 7,506 eligible items and is pinned by model and
SHA256 in the loader.

## Methods

- `Popularity`: source positive-interaction count for each item, fit on the
  complete source log.
- `GPT-5.4-mini, H20`: the repository's target-response listwise scorer with
  the 20-row observed history.
- `GPT-5.4-mini, no history`: identical candidates, metadata, model, and
  request, but without the history block. This is an ablation rather than a
  recommender baseline.

## Test results

Metrics are averaged over eligible candidate seeds within user and then over
users.

| Target regime | Method | NDCG@5 | HR@1 |
| --- | --- | ---: | ---: |
| Standard temporal reference | Popularity | 0.5659 | 0.5162 |
| Standard temporal reference | GPT-5.4-mini, H20 | 0.5708 | 0.5216 |
| Standard temporal reference | GPT-5.4-mini, no history | 0.5408 | 0.4858 |
| Random OOD | Popularity | **0.4782** | **0.3582** |
| Random OOD | GPT-5.4-mini, H20 | 0.4438 | 0.3131 |
| Random OOD | GPT-5.4-mini, no history | 0.3911 | 0.2498 |

Exact ranking denominators:

| Target regime | Total groups | Mixed groups | All zero | All positive | Users in metric |
| --- | ---: | ---: | ---: | ---: | ---: |
| Standard temporal reference | 1,500 | 1,457 | 19 | 24 | 494 |
| Random OOD | 1,500 | 1,136 | 364 | 0 | 429 |

Paired user-bootstrap NDCG@5 comparisons:

| Target regime | Contrast | Mean difference | 95% CI |
| --- | --- | ---: | ---: |
| Standard temporal reference | GPT H20 minus no history | +0.0301 | [0.0111, 0.0483] |
| Standard temporal reference | GPT H20 minus Popularity | +0.0049 | [-0.0177, 0.0284] |
| Random OOD | GPT H20 minus no history | +0.0527 | [0.0287, 0.0763] |
| Random OOD | GPT H20 minus Popularity | -0.0345 | [-0.0669, -0.0038] |

The paired random-target comparisons contain 1,136 eligible
`seed × user` groups from 429 users. The standard-target comparisons contain
1,457 groups from 494 users.

## Interpretation

The positive H20-minus-no-history difference on randomized exposures is
evidence that GPT uses the pre-intervention standard-feed history and transfers
some user-specific ranking signal to the new exposure regime. The result is
therefore not explained by candidate text prior alone.

That transfer is not strong enough to beat the simplest collaborative
statistic. GPT and Popularity are tied on the standard temporal reference, but
GPT is lower than Popularity on the randomized target. Under this protocol,
the result does **not** support a claim that the LLM extrapolates across the
exposure shift better than classical recommendation.

The defensible paper claim is narrower:

> Standard-regime behavioral history remains useful to the LLM under future
> randomized exposure, but the resulting semantic simulator does not
> outperform source-item popularity.

Raw standard and random metric levels should not be subtracted and interpreted
as a pure policy-shift penalty because the candidate distributions differ and
the random target is also later in time.

## Cost and artifacts

The full run made 6,000 successful listwise requests and produced 60,000 GPT
prediction rows. One transient failed request was resumed from the other 5,999
content-addressed checkpoints. Final inference cost was USD 7.4077. The
four-request format smoke cost USD 0.0049.

Generated artifacts are under:

```text
outputs/ood/kuairand_policy_shift_v2/
```

They include the task audit, prompt/cost preflight, prompt example, predictions,
per-group metrics, exact cell denominators, paired bootstrap comparisons, API
usage, error accounting, and checkpoint provenance.

## Limitations

- Only Popularity is included as a classical baseline in this first run.
- Candidate groups combine ten separate logged exposures; they are not
  simultaneous production slates and do not estimate policy value.
- The OOD target combines temporal and exposure-regime change.
- Ranking metrics necessarily exclude degenerate all-zero and all-positive
  groups; their prevalence is reported explicitly.
- This was an exploratory run rather than an externally preregistered
  confirmatory experiment.
